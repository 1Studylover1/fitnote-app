FitNote 网页更新：身体信息支持拍照/上传图片

本次需要替换 GitHub 仓库根目录中的两个文件：
- index.html
- sw.js

步骤：
1. 解压本更新包。
2. 打开 https://github.com/1Studylover1/fitnote-app/upload/main
3. 上传解压后的 index.html 和 sw.js（不要上传 ZIP 本身）。
4. 点击 Commit changes 保存。
5. 等待 GitHub Pages 部署完成后，在 FitNote 页面刷新。如果之前已添加到主屏幕，完全关闭再重新打开；必要时刷新网页或稍等缓存更新。

新增功能：
- 身体记录可以直接拍照。
- 可以从相册/文件上传图片。
- 图片附在该条身体记录中，并显示在历史记录里。
- 图片仅保存在当前浏览器本地，不会上传到 GitHub。

注意：这次图片功能与原有食物照片一样，属于照片留档，不会自动 OCR 识别体测报告中的数值。体重、体脂率和围度仍需手动填写。
